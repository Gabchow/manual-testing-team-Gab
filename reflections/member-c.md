What makes a test positive or negative?

If log in success and is same as the expected results it is positive but if input is wrong, shows error and is the same as the expected results it is negative.

A positive test uses valid input, and it passes when the system works and matches the expected result. A negative test uses invalid input, and it passes when the system shows the expected error.

Why can a negative test pass?
Because the system rejects bad input correctly. The actual result matches the expected result.
