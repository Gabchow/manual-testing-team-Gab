1. What makes a test positive or negative?

The test is positive if the value of the input is in the intended requirements for the input.
The test is negative if the value of the input is outside the intended requirements for the input.

2. Why can a negative test pass?

Passing of the test refers to if the test had the intended results, either Positive or Negative.
The actual psotive or negative results do not reflect if the test has passed or not.

3. How did equivalence partitioning help you select data?

It helped me be more selective to the test values i chose, narrowing down the wide range of 
possible input values, into individual partitions, allowing us to choose 1 value per partition
to test.

4. What did boundary testing help you investigate?

Boundary testing helped me investigate the immediate neighbouring value that crosses over
from valid to invalid values.
