1. What makes a test positive or negative?
A test is positive if it is expected to pass e.g. within boundary values and negative if it is expected to fail e.g. outside boundary values


2. Why can a negative test pass?
Because pass refers to whether the actual result meets the expected result. Passing or failing is unrelated to whether the test is positive or negative.


3. How did equivalence partitioning help you select data?
It divides data into groups, such as valid partitions (values within the boundary) and invalid partitions (values outside boundary), so it allows us to select 1 value from each partition instead of testing every single value.


4. What did boundary testing help you investigate?
Boundary testing helps investigate the value that will change the input value to go from incorrect to correct or vice versa.
